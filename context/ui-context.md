# UI Context

## Current (spec `0.8`–`0.9`)

Quiet document. Light paper, ink type, no brand hue. IBM Plex Serif (H1) + Sans (body) + Mono (home kicker). Work is lists and articles. Almost no motion. No gradient text. Light only. No theme toggle. No Earth, timeline, tech-icon grid, or archive card pages.

## Theme

Paper/ink. No dark-mode class or `next-themes`. Do not add a theme toggle unless a spec says so.

## Colors

Theme tokens live in Tailwind `theme.extend.colors`. Prefer these class names over new hex values.

| Role           | Tailwind token | Value     | Typical use                         |
| -------------- | -------------- | --------- | ----------------------------------- |
| Paper          | `background`   | `#F4F1EA` | Body, v2 `main`, nav, ContactCta    |
| Paper (alias)  | `secondary`    | `#F4F1EA` | Same paper                          |
| Ink fill       | `primary`      | `#1C1917` | Buttons, RD mark                    |
| Headings       | `textDark`     | `#1C1917` | H1–H3, names, titles                |
| Body / muted   | `textLight`    | `#57534E` | Paragraphs, nav idle, dates         |
| Button hover   | `accent`       | `#2C2825` | `hover:bg-accent` on filled CTAs    |

Hairlines: `border-black/10`. Link hover: underline, not a new color.

Do **not** add forest green, teal, or blue as a brand color. Do not restore rainbow tag gradients.

## Typography

Loaded in `src/app/layout.tsx` via `next/font/google`. CSS variables `--font-sans`, `--font-display`, `--font-mono`.

| Role    | Font                         | Tailwind        | Use                                      |
| ------- | ---------------------------- | --------------- | ---------------------------------------- |
| Body/UI | IBM Plex Sans 400–700        | `font-sans`     | Body, nav, buttons, h2+                  |
| Display | IBM Plex Serif 600/700       | `font-display`  | H1 only                                  |
| Kicker  | IBM Plex Mono 400/500        | `font-mono`     | Home kicker only                         |

Scale commonly used:

- Home name: `font-display text-4xl md:text-5xl lg:text-6xl font-bold text-textDark`
- Page titles: `font-display text-4xl md:text-5xl font-bold text-textDark`
- Section titles: `text-2xl` / `text-3xl font-bold text-textDark` (sans)
- Body: `text-lg text-textLight`
- Kicker: `font-mono text-xs uppercase tracking-wider`

## Border Radius

| Context                    | Classes        |
| -------------------------- | -------------- |
| V2 CTAs (filled + outline) | `rounded-full` |
| RD mark                    | `rounded-md`   |
| Work article media         | `rounded-lg`   |

## Spacing and width

- V2 pages and nav/footer: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`.
- Reading column: `max-w-3xl` where already used.
- Section vertical rhythm: `py-16` / `py-20`.
- Sticky nav height: `h-16`.

When adding a page, **pick one width system and stick to it for that page**. Do not mix `container` and `max-w-7xl` in the same section row.

## Component Library

No shadcn/ui. No Radix. Components are hand-written under `src/components/`.

Reuse existing pieces before creating new ones:

- `MainNavigation` — site chrome
- `Footer` — every page that currently includes it
- `ContactCta` — work/writing contact band
- `WorkArticleView` — `/work/[slug]`

## Layout Patterns

- **Chrome**: sticky paper nav, hairline `border-b border-black/10`, RD mark, text links, CV pill. Active link is underline. Mobile hamburger + Framer collapse.
- **Home / inner v2**: document column, paper `bg-background`, serif H1, hairline lists, footer hairline.
- **Primary button**: `bg-primary text-white … rounded-full hover:bg-accent`.
- **Secondary button**: `border border-primary text-primary … rounded-full hover:bg-primary hover:text-white`.

## Icons

- **react-icons/fa** for the mobile nav hamburger and close. Inline size `h-6 w-6`.
- Nav CV has **no** download icon.
- Do not add lucide-react unless a spec says so.

## Motion

- Document pages: none.
- Mobile nav height: Framer `AnimatePresence` in `MainNavigation`.
- `globals.css`: `html { scroll-smooth }`.
- No Three.js.
