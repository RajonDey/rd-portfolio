# 2.4 Legal discovery

## Status

`done`

## Goal

Signed-in `/desk` can scan public, no-login sources (Arbeitnow plus a curated DE/NL ATS list), dedupe, and run each posting through the `2.2` fit gate. Apply hits can open the posting and download a `2.3` pack. Nothing is stored. Auto-apply stays out.

## Why

Moves the desk from paste-only to “it searched for me” without LinkedIn, Indeed, or StepStone scraping.

## In scope

- `POST /desk/discover`. Session required. GET 404. Same `2.1` lock as the rest of `/desk`.
- Arbeitnow: `GET https://www.arbeitnow.com/api/job-board-api?page=1` (no API key). One page per scan.
- Greenhouse: list without `content=true`. Fetch the job body only for title-matching, location-kept postings (max 15 per board).
- Curated company boards only, from `src/lib/desk/sources.ts`. Adapters: Greenhouse, Lever, Ashby, Personio (XML, no extra npm dep).
- Starter boards (verified public feeds, DE/NL, overlay industries). Owner may add rows later without a new spec; do not invent boards beyond this list in this unit:

  | Provider | Token | Company |
  | --- | --- | --- |
  | greenhouse | `contentful` | Contentful |
  | greenhouse | `doctolib` | Doctolib |
  | greenhouse | `adahealth` | Ada Health |
  | greenhouse | `celonis` | Celonis |
  | greenhouse | `n26` | N26 |
  | greenhouse | `bird` | Bird |
  | ashby | `mollie` | Mollie |
  | personio | `personio` | Personio |

- Allowlisted hosts only (no owner-supplied fetch URL): `www.arbeitnow.com`, `boards-api.greenhouse.io`, `api.lever.co`, `api.ashbyhq.com`, `{token}.jobs.personio.de`.
- User-Agent `rd-portfolio-desk/2.4 (personal)`. 8s timeout per request. Parallel fetches. One source failing does not fail the scan.
- Normalize to title, company, location, url, description (HTML stripped), remote, source.
- Location prefilter: keep Germany / Netherlands / Canada / named overlay cities / remote. Drop Portugal, Estonia, US before scoring. Do not search Tokyo.
- Title prefilter: overlay titles only (Senior SWE / Full-Stack / Senior Frontend / Tech Lead).
- Dedupe by normalized posting URL, then by `company + title`.
- Score with `scoreJobText` (`2.2`). No LLM. No new scorer.
- UI: Find jobs on signed-in `/desk`. Show Apply hits only (max 20). Skipped count as a note. Failed sources as notes. Each Apply row: title, company, location, source, Open posting, Download CV, Download letter (`2.3` pack with that JD).
- Paste-JD form from `2.2` stays. Owner can still paste a LinkedIn URL there.
- No writes to `public/`. No database. Scan is live, not persisted (`2.6` is the tracker).
- Patch architecture, overlay desk-boundary, tracker, spec README.

## Out of scope

- LinkedIn login, Easy Apply, Indeed scrape, StepStone as a core engine
- Weekly email and the 5–8 weekly cap (`2.5`)
- Application tracker (`2.6`)
- Auto-apply / posting to Greenhouse apply APIs
- Canada Job Bank, NL sponsor register, Tokyo one-offs
- Workday / SmartRecruiters / Recruitee adapters
- Inventing employers, titles, or a larger company watchlist
- Production hosting of `/desk`
- Extra npm dependencies

## User-facing behavior

1. Sign in on `/desk`.
2. Click Find jobs. Wait for the scan.
3. Apply rows appear (or “No apply-fit jobs in this scan.”). Skipped count is a note.
4. Open posting in a new tab. Download CV / letter for that row. Review and send by hand.
5. Paste a JD below as before when the posting is not in this scan.
6. Public site unchanged.
