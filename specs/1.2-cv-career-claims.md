# 1.2 CV career claims

## Status

`done` <!-- draft | ready | in-progress | done -->

## Goal

Every public career claim that states an SJ Innovation title, a role start date, or a years-of-experience count matches the CV. Docs that agents copy from (`career-brief`, job-search profile, the `data.ts` lock) carry the same facts so the old timeline is not written back.

## Why

Visa officers compare the portfolio with the CV. Home and About currently show one job, `Module Lead (Frontend), May 2019 - Present`. The CV splits that tenure into three titles. `context/career-brief.md` still says `6+ years`.

## In scope

- SJ Innovation experience in `src/lib/data.ts` is three roles, newest first, plus the existing freelance role.
- Current-role date range in `src/lib/experience.ts` starts Jun 2023. Corporate start for years, copyright, and “Building since” stays May 2019.
- Home current-role line uses the current title and `getCurrentRoleDateRange()` so it cannot say Module Lead began in 2019.
- About lists every role. Empty description lists are not rendered.
- Years label stays `getYearsOfExperienceLabel()`. It must not be written as `6+`.
- Career brief, job-search profile, and the specs that lock these strings, updated so they do not reintroduce the old title or date.
- Desk prep “current role” sentence, because it states the employment title.

## Out of scope

- Visual redesign, nav, or new pages.
- Changing the public H1 / `SITE_ROLE` / JSON-LD `jobTitle` / OG card (`Senior Software Engineer`). Those lines have no employment start date.
- Rewriting experience bullets, project roles, testimonials, or certificate text.
- Adding an education section. No page states education dates. The degree is locked in the career brief only.
- Job-search target titles (`Tech Lead / Module Lead (Frontend)` as an application alias). That alias is not a dated employment claim.
- Inventing per-role bullets for 2019–2023. Existing bullets stay on Module Lead.

## User-facing behavior

1. Open `/`. H1 is still Rajon Dey. Role line is still Senior Software Engineer. The employment line reads `Module Lead, SJ Innovation LLC. Jun 2023 – Present.`
2. Open `/about`. Experience lists, in order: Module Lead (Jun 2023 – Present, existing bullets), Senior Frontend Developer (May 2022 – Jun 2023), Frontend Developer (May 2019 – May 2022), Software Developer (Freelance / Contract) (2015 – 2018, existing bullets).
3. Footer still says `Building since May 2019.` Meta description still uses the computed years label, which is `7+ years` as of October 2026, never `6+`.
