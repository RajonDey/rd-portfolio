# 2.20 Search query matrix

## Status

`done`

## Goal

Overlay search queries and title aliases are encoded in TypeScript so discovery does not invent titles. Mix stays about 70% SWE / full-stack / Tech Lead and 30% Senior Frontend. Sources that already accept a search string can use these queries; Arbeitnow stays page 1 until a later spec.

## Why

`2.4` dumps Arbeitnow page 1 and full ATS boards, then title-filters. The overlay already listed title + location shapes but code only has regexes. Lead Frontend is missing as a Tech Lead alias. Depends on `2.18` and `2.19` so extra recall is not unranked junk.
