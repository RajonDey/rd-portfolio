# 2.12 Apply-file policy

## Status

`done`

## Goal

The file the owner attaches to an application is the matching Google Doc (SWE or Frontend). Desk still compiles an ATS-plain PDF, labeled as a draft. Desk and the Monday reminder show which Doc to use. React-PDF layout does not change.

## Why

The designed CV lives in Google Docs. The desk PDF is Helvetica and not up to that mark. Email no longer attaches PDFs (`2.9`). The owner needs a clear apply file so Drive does not fill with desk copies. See `context/progress-tracker.md`.

- Lock the policy in `context/job-search-profile.md` (Apply file section + weekly loop step 5). Public site CV button stays `CV_URL` (web PDF). Do not change About or nav.
- Add `SWE_CV_DOC_URL` in `src/lib/site.ts` for the SWE Google Doc already named in the overlay (`1_4CDSLUAE8K2_QRXg12bkbvPgIrSY8jzJibTDDiyMJA`). Frontend stays `FRONTEND_CV_URL`.
- Fit `cvUrl` is that Google Doc (SWE or Frontend), not the public web PDF.
- Signed-in Inbox Apply rows and Paste Apply results: underlined Doc link (`SWE Doc` / `Frontend Doc`) plus heading `Apply CV`. Pack CV download label becomes `ATS draft CV`. Letter stays `Download letter`.

## User-facing behavior

1. Find jobs or Evaluate. Apply hit shows Apply CV: SWE Doc or Frontend Doc (opens Google Doc).
2. Owner exports or copies from that Doc for the company form.
3. Optional: ATS draft CV and letter from Desk. Delete the download after send (`2.11`).
4. Monday mail includes the Doc link. Open Desk if they need a letter draft.
5. Public site CV button unchanged.
