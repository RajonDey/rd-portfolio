# 2.19 Fit score

## Status

`done`

## Goal

Every apply-eligible job gets a rules-only score from 0–100. Inbox and Monday mail show and sort by that score (best first), not recency. Skip stays skip; score does not override `2.18` vetoes.

## Why

The quality bar is precision, not volume. Cap 8 currently takes the newest Apply hits, so a weaker new posting can beat a Berlin visa-sponsor Tech Lead. `2.2` already lists signals; it does not rank. Depends on `2.18` being `done`.

## In scope

- Add `score: number` (0–100 integer) to `FitResult`. Skip is `0` and `decision: "skip"`. Apply uses the matrix below, then `Math.min(100, total)`.
- Points among apply-eligible only:

  | Pts | When |
  | --- | --- |
  | +10 each, cap +30 | React, Next.js, TypeScript (existing `STACK_PATTERNS`) |
  | +25 | Relocation / visa / Blue Card / kennismigrant / hire from abroad |
  | +20 | Node.js or Python / FastAPI |
  | +15 | Senior / Lead / Module Lead / Tech Lead (existing title patterns) |
  | +10 | Overlay industry hit (existing `INDUSTRY_PATTERNS`) |
  | +10 | Remote DE / NL / CA (not generic worldwide) |
  | +0 | Remote worldwide with no geo/visa (allowed only if it still passed `2.18`) |
  | −15 | LeetCode/DSA mentioned as one round among others (not the `2.18` hard skip) |
  | −10 | CS degree preferred (required stays `2.18` skip) |

- Optional +5 only if the JD text itself states company size in the 50–500 / mid-size / scale-up range. Do not fetch headcount. Do not invent size.
- German-as-a-plus: existing note only. No score change.
- `runDiscovery`: sort primary Apply and overflow each by `score` desc, then `createdAt` desc. Caps unchanged (20 Inbox, 8 weekly, 2 overflow).
- UI: each Inbox Apply row and each weekly section shows the integer score as text (e.g. `78`). Paste Evaluate result shows it too.
- Patch overlay quality bar (rank by score), progress tracker, spec README.

## Out of scope

- New discovery sources or query HTTP (`2.20` / `2.21`)
- Team-size APIs, LinkedIn company pages, Clearbit
- LLM judge
- Changing vetoes from `2.18`
- Auto-apply, public site
- Equalizing Remote Worldwide with visa/relocation (+25)

## User-facing behavior

1. Sign in. Find jobs. Apply rows are best-fit first. Each row shows a 0–100 score.
2. Paste Evaluate: Apply includes the score; Skip stays 0 with red flags.
3. Monday mail order matches Inbox (score, then newer). Cap still 8 + 2 overflow.
4. Public site unchanged.
