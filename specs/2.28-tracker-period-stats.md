# 2.28 Tracker period stats (last week / last month)

## Status

`draft`

## Goal

Tracker shows simple period counts: Applied this week and this month (plus all-time Applied from `2.27`). Derived from existing `updatedAt` on tracker rows. No charts, no database.

## Why

Owner wants at-a-glance progress over time after the simple `Applied: N` lands in `2.27`. See `context/progress-tracker.md`.

## In scope

- Under the `Applied: N` line (or beside it): quiet text
  - `This week: N`
  - `This month: N`
- Counts = tracker jobs with `status === "applied"` whose `updatedAt` falls in the period.
- **Week:** last 7 rolling days from now (not calendar week) — lock unless owner prefers Monday–Sunday.
- **Month:** last 30 rolling days (not calendar month) — lock unless owner prefers calendar month.
- Same paper/ink muted text. No charts, sparklines, or cards.
- Copy in `src/lib/desk/copy.ts`. Progress tracker + README.

## Out of scope

- Interview / Skip / Silence period stats (unless added as a follow-up)
- Changing when `updatedAt` is set (already set on each upsert)
- Timezone picker (use local browser or server ISO compare consistently — prefer compare in the client from ISO strings)
- Export CSV, email digest of stats
- Reopening mark flash (`2.27`)

## User-facing behavior

1. Open Tracker. See `Applied: N` (all-time), `This week: A`, `This month: B`.
2. Mark Applied today → week and month counts go up on next tracker refresh.
3. Public site unchanged.
