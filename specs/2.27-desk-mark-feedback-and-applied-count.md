# 2.27 Desk mark feedback and Applied count

## Status

`done`

## Goal

Marking Applied or Skip on Inbox shows a brief confirmation, then the row leaves. Tracker shows a simple `Applied: N` count. No new colors beyond paper/ink muted text. No week/month stats in this unit.

## Why

Owner review: Applied feels like nothing happened because the row vanishes with no feedback, and there is no at-a-glance Applied total. See `context/progress-tracker.md`.

## In scope

### Inbox mark flash (`2.23` behavior kept)

- On successful **Applied** or **Skip** from Inbox (and Paste Apply/Skip when a URL is present):
  1. Replace the action row with muted copy for ~1 second: `Saved · Applied` or `Saved · Skip`.
  2. Then remove the row from the Inbox list (same as today).
- On failure: keep existing `Could not save that mark.` Do not flash success. Do not remove the row.
- While pending: disable both actions (already). Optional quiet `Saving…` is allowed; prefer the flash only after success.
- No green/red status colors. Use `text-textLight` for the flash line. No new brand hues (`context/ui-context.md`).

### Tracker count line

- Under Tracker intro (or directly under the H2): one quiet line `Applied: N` where `N` is the count of tracker jobs with `status === "applied"`.
- Update when the tracker list reloads (including after `DESK_TRACKER_CHANGED`).
- Do not invent interview/skip/silence totals in this unit (can show later if wanted). Empty tracker still shows `Applied: 0` or hide the line when the list is empty — **lock: always show `Applied: N`**.

### Copy + docs

- Strings in `src/lib/desk/copy.ts`.
- Patch progress tracker + spec README. Overlay optional one line under weekly loop step 6.

## Out of scope

- Last week / last month stats (`2.28`)
- Color-coded status pills, dashboard cards, charts
- Changing gist shape or adding fields
- Totals for Interview / Skip / Silence (unless trivial later)
- Public site
- Auto-apply

## User-facing behavior

1. Inbox: click Applied. Buttons become `Saved · Applied` (muted) for about one second. Row disappears. Tracker lists the job and `Applied: N` increments.
2. Inbox: click Skip. Same flash with `Saved · Skip`, then row gone.
3. If save fails: error line; row stays; count unchanged.
4. Open Tracker: see `Applied: N` above the list.
