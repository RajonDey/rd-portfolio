# 2.8 Desk UI

## Status

`done`

## Goal

Signed-in `/desk` is a three-section document: Inbox, Tracker, Paste a job. Each job title is the posting link. Status and pack actions are quiet, so a scan is readable instead of a wall of identical pills.

## Why

`2.4`–`2.6` stacked Find jobs, tracker, and paste on one page and reused the same outline pills for every action. Titles were plain text; the posting sat on a separate “Open posting” line. The owner already uses this page to review and apply. Layout only; no new sources, email, or pack rules. See `context/progress-tracker.md`.

## In scope

- Same URL: `/desk`. No `/desk/inbox` or other desk routes.
- Signed-in layout, top to bottom:
  1. Existing kicker + H1
  2. Sign out (outline pill), immediately under the H1, not at the bottom
  3. **Inbox** — Find jobs scan
  4. **Tracker** — recorded jobs
  5. **Paste a job** — existing evaluate form, inside a closed `<details>`
- Section breaks: `border-t border-black/10` plus an `h2` (`text-2xl font-bold text-textDark`).
- Job title is an external link (`target="_blank"` `rel="noopener noreferrer"`) when a posting URL exists. Always underlined (`underline underline-offset-4`) so it does not look like a heading. If there is no URL, the title stays text (not a link).
- Drop “Open posting” from Inbox and Tracker rows. The title is that action.
- Hairline between job rows: `border-b border-black/10` on each `li`, not on the last item. `py-6` (or equivalent). No cards, no shadows, no new colors.
- **Inbox row:** title (link) · company · location · source · application title (muted). Pack: two text links, Download CV / Download letter (same hover-underline as other desk text links, not pills). Status: **Applied** and **Skip** only, as text buttons (underline on hover), not `rounded-full` pills. After Applied or Skip, the row still leaves the scan list (`2.6`).
- **Tracker row:** title (link) · company · current status as a word. One native `<select>` to change Applied / Interview / Skip / Silence. **Clear** as a text link only on Tracker. Same POST `/desk/track` as today.
- **Paste Apply result:** pack as text links. If a job URL was submitted: Applied and Skip only (same as Inbox). Interview / Silence / Clear stay on Tracker.
- **Paste Skip result:** no pack. If a job URL was submitted: Skip text button so the URL can be recorded.
- Find jobs and Evaluate stay primary filled pills. Sign out stays the existing outline pill. Password form unchanged.
- Reading column: keep `max-w-3xl` on signed-in sections. Page wrapper stays `max-w-7xl` like other v2 pages.
- Copy in `src/lib/desk/copy.ts` only. New strings listed below. Stop rendering `DESK_OPEN_POSTING` on Inbox and Tracker.
- `"use client"` stays on the existing desk leaves. No new npm deps. No Radix / shadcn.
- Patch `context/progress-tracker.md` and this spec’s status when the unit is done.

## User-facing behavior

1. Sign in on `/desk`. Password form is unchanged.
2. See Desk title, then Sign out, then Inbox.
3. Click Find jobs. Apply rows appear under Inbox. Click a title to open the posting in a new tab.
4. Download CV or letter from the text links. Mark Applied or Skip. The row leaves Inbox and shows in Tracker.
5. On Tracker, change status with the select, or Clear to let the job return.
6. Open Paste a job only when the posting was not in the scan. Evaluate as today.
7. Public site unchanged.

## UI notes

- Layout: one document column. Three sections with hairlines. Paste in `<details>` default **closed**; summary is the Paste a job `h2`. Inbox and Tracker stay open.
- Tokens: paper `background`, `textDark` / `textLight`, `border-black/10`. Primary pill = Find jobs / Evaluate. Outline pill = Sign out only.
- Job title links: `text-textDark underline underline-offset-4`. Pack and status text actions: `text-textDark hover:underline underline-offset-4`, not pills.
- Tracker `<select>`: `border border-black/10`, paper background, `text-textDark`. No custom dropdown library.
- Breakpoints: wrap text actions. No new breakpoint system. No Footer. No public nav link.
- Do not use `rounded-full` on Inbox/Tracker status or pack controls.
