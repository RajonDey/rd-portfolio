## Status

`done`

## Goal

The v2 document (`/`, `/work`, `/work/[slug]`, `/writing`, `/about`, nav, footer) reads as paper and ink: a display/body type pairing, warm paper, one quiet accent, pill CTAs. Not a Roboto SaaS landing. Not Gourob’s forest green. Tutorial surfaces stay on disk until `0.9`.

## Why

`0.4`–`0.7` shipped the document structure on v1 tokens (Roboto, pure black/white, `rounded-lg`, `shadow-lg` nav). `context/portfolio-v2.md` deferred type, paper, and accent to this unit so we style the right pages once. Listed next in `context/progress-tracker.md`.

## User-facing behavior

1. Open `/`. Page is warm paper, not stark white. Name is serif. Kicker is mono, small, tracked. Body is sans. Work (filled pill) and Writing (outline pill). No Roboto. No forest green.
2. Nav sits on paper with a hairline bottom border, not a heavy drop shadow. CV is a filled pill, **text only** (no download icon). Active link is ink + underline, not a gray chip.
3. `/work`, `/writing`, `/about`, `/work/[slug]` match: paper background, serif page titles, sans body, hairline lists, same pills where a filled button already exists.
4. Footer: hairline, no decorative gradient bar.
5. `/projects` and other archives may pick up paper/ink and lose rainbow tags. Do not redesign their grids. They stay off-nav until `0.9`.

## UI notes

### Type

Load from Google Fonts. Do not use Inter, Geist, or Roboto.

| Role | Face | Tailwind | Use |
| ---- | ---- | -------- | --- |
| Body / UI | IBM Plex Sans (400, 500, 600) | `font-sans` | Body, nav, buttons, lists |
| Display | IBM Plex Serif (600, 700) | `font-display` | H1 on v2 pages (name, About/Work/Writing titles, article titles) |
| Kicker | IBM Plex Mono (400, 500) | `font-mono` | Home kicker only (`FULL-STACK · LLM SECURITY`) |

`h2`/`h3` stay **sans**, semibold/bold. Only H1 is serif.

Map leftover `font-roboto` to `font-sans` so unmounted v1 files do not 404 a family.

### Color (lock these hex values)

Keep existing token **names**. Change the values.

| Token | New value | Role |
| ----- | --------- | ---- |
| `background` | `#F4F1EA` | Paper. Body and v2 `main`. |
| `secondary` | `#F4F1EA` | Same paper (no second white). |
| `primary` | `#1C1917` | Ink. Filled buttons, RD mark, strong UI. |
| `textDark` | `#1C1917` | Headings, names, titles. |
| `textLight` | `#57534E` | Body, dates, muted nav. |
| `accent` | `#2C2825` | Filled-button hover. Not a brand hue. |

Quiet accent for **focus / link hover** only: `text-textDark` plus underline. Do **not** introduce green, teal, or blue as a brand color.

Contrast: ink on paper must stay readable. Do not lighten `textLight` further.

### Shape

- Filled and outline CTAs that already exist on v2 (home Work/Writing, nav CV, About CV, ContactCta CV/Email): `rounded-full`.
- Text links stay text. Do not pill GitHub/Email/LinkedIn.
- RD mark: keep the square tile; `rounded-md` is enough. Do not restyle it as a new logo.
- Work article images: keep `rounded-lg` (media, not a CTA).

### Chrome

- Nav: `bg-background border-b border-black/10 sticky`. No `shadow-lg`.
- Active nav: `text-textDark underline underline-offset-4`. Idle: `text-textLight hover:text-textDark`. No `bg-primary/10` chips.
- CV pill: same filled classes as today (`bg-primary text-white … hover:bg-accent`) but `rounded-full` and **no** `FaDownload`.
- Body: `bg-background text-textLight`.
- V2 mains: replace `bg-white` with `bg-background`.
- `ContactCta`: paper, `border-t border-black/10`, drop `bg-gray-50`.
- Footer: `border-t border-black/10`, drop `.decorative-divider`. Width system may stay `container` or match `max-w-7xl`; pick one and do not mix in the same row.
- Lists: keep `divide-y divide-gray-200` or use `border-black/10`. Either is fine if hairline and quiet.

### Gradient tags

In `globals.css`, make `.blue-text-gradient`, `.pink-text-gradient`, `.green-text-gradient` solid `text-textLight` (no clip, no fill transparent). Do not delete the class names (archive cards still reference them).

### Motion / breakpoints

- Add none. Keep existing mobile nav Framer collapse.
- Stack as now (`flex-col sm:flex-row` for CTA rows).
- Reading column stays `max-w-3xl` where it already is.

### Light only

No `dark:` palette. No `next-themes`.
