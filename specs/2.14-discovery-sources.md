# 2.14 Discovery sources

## Status

`done`

## Goal

Find jobs still scans Arbeitnow page 1 plus the existing curated ATS boards. Netherlands **Arbeitnow** hits are kept only when the company is on the IND public register of recognised sponsors. Extra ATS tokens stay owner-named. Canada Job Bank is not scraped.

## Why

`2.4` deferred the NL sponsor register and Job Bank. The overlay’s Netherlands path is kennismigrant via an IND-recognised sponsor. Arbeitnow is noisy; the register is the legal, no-login way to raise that bar. The owner proceeded without naming extra Greenhouse/Ashby/Personio companies. See `context/progress-tracker.md`.

## In scope

- Fetch the official IND public register (work / highly skilled migrant) from a fixed URL. Allowlist `ind.nl` / `www.ind.nl`. Same 8s timeout and 3MB cap as other discovery fetches. Parse organisation names from the HTML table (`th scope="row"`).
- After the existing location + title prefilter: if the job is from Arbeitnow **and** looks Netherlands-based **and** the register loaded, drop it unless the company matches a sponsor. Matching is case-insensitive after stripping legal suffixes (B.V., N.V., GmbH, Inc, Ltd, LLC). Fail-open if the register fetch or parse fails (keep the job; add a source error).
- Curated `ATS_BOARDS` are not re-filtered by IND (already owner-named in `2.4`).
- Keep the current eight ATS rows. Owner may add tokens in `src/lib/desk/sources.ts` later; this unit does not invent companies.
- Copy: Inbox intro names the IND rule. Weekly mail uses the same `runDiscovery` filter.
- Patch overlay search/sources, architecture allowlist, progress tracker, spec README.

## Out of scope

- Inventing extra Greenhouse / Ashby / Personio / Lever tokens
- Scraping Canada Job Bank HTML, Apify, or monthly open.canada.ca CSV dumps (too large and stale for a 60s scan; no live public JSON API)
- LinkedIn login, Indeed, StepStone
- Using the 12k sponsor names to guess ATS board tokens
- Workday / SmartRecruiters adapters
- Tokyo / HENNGE search
- Auto-apply
- Interview prep (`2.15`)
- Reopening `2.0`–`2.13`

## User-facing behavior

1. Sign in on `/desk`. Click Find jobs.
2. Scan is Arbeitnow + the same curated boards as `2.4`.
3. Netherlands Arbeitnow rows appear only when the company is on the IND register. DE/CA/remote-without-NL, and all ATS board rows, are unchanged.
4. If the IND fetch fails, those NL Arbeitnow rows still appear and “IND sponsor register” is listed under sources that failed.
5. Paste a job for LinkedIn, Job Bank, or any posting the scan missed.
6. Public site unchanged.
