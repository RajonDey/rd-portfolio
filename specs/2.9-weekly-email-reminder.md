# 2.9 Weekly email as reminder

## Status

`done`

## Goal

The Monday email is a reminder: posting links, CV variant, work hints, and a link to `/desk`. It does not attach CV or letter PDFs. The owner downloads a pack from Desk when they apply.

## Why

`2.5` emailed up to 16 PDFs per week. Those files filled the inbox and Drive. The owner wants email as a nudge only. Packs stay on `/desk` (`2.3`, `2.8`). Cap stays 8. See `context/progress-tracker.md`.

## In scope

- Same CLI and GitHub Action: `npm run desk:weekly` and `.github/workflows/desk-weekly.yml`. Cap 8. Zero Apply still sends (or dry-runs) the empty mail.
- Email HTML: intro, one Desk link (`SITE_ORIGIN` + `/desk`), then per job: title (as posting link), company, location, application title, work URLs when the fit has them, IEEE URL when `includeIeee`. Footer: skipped / scanned / source errors. No PDF attachments on send or dry-run.
- `--dry-run`: write `email.html` and `subject.txt` under `.desk-out/{date}/`. Do not write PDFs. Do not call Resend.
- Send path: Resend HTML only. Omit `attachments`. Same `to` / `from` env as `2.5`.
- Copy in `src/lib/desk/copy.ts`. No em dashes.
- Patch architecture, overlay desk-boundary, project overview, tracker, spec README.
- Do not change `/desk` UI, fit, pack POST, discovery sources, tracker store, or the weekly cap.

## Out of scope

- Auto-submit
- Pack file cleanup (`2.10`)
- Operating loop overlay (`2.11`), apply-file policy (`2.12`)
- New ATS sources
- Changing Resend, schedule, or adding another mail provider
- Reopening `2.0`–`2.8` spec files
- Inventing jobs, employers, or metrics

## User-facing behavior

1. Local: `npm run desk:weekly -- --dry-run`. Open `.desk-out/{date}/email.html`. No PDFs in that folder.
2. Monday Action (or send without `--dry-run`): one email with posting links and Open Desk. No CV or letter attached.
3. Owner opens the posting, opens Desk, downloads a pack there if needed, applies by hand.
4. Public site unchanged.

Update `DESK_WEEKLY_INTRO`:

Per-job application title is the CV variant hint. Work lines use `DESK_WORK_LABEL`. IEEE uses `DESK_IEEE_LABEL` and the existing IEEE title/URL from the fit.
