# 2.30 Desk workbench

## Status

`done`

## Goal

Signed-in `/desk` is a workbench: one header, three panels (Inbox, Apply, Tracker), denser rows, and the outside-board filter shown once. Same data, same actions, paper and ink. The public site stays a document.

## Why

`2.8` laid Desk out as a reading column. Inbox, Also apply, Tracker, Apply docs, Paste, and Notes now stack into a long page. The shared filter repeats in spirit across six boards, job rows use article type size, and Applied is buried in Tracker. The owner uses this page every week to choose, send, and record. Layout only. See `context/progress-tracker.md`.

This spec supersedes the signed-in layout rules in `2.8` (single column of open sections, `max-w-3xl`, Sign out as an outline pill, Paste closed on the main page). It does not reopen fit, discovery, packs, or tracker rules.

## In scope

- Same URL: `/desk`. No new routes, no query tab, no nav or sitemap link.
- Signed-in page, top to bottom:
  1. Existing kicker + serif H1
  2. Loop line, store line, gist warning (warning only when already shown)
  3. `Applied: N` once the tracker GET has returned
  4. Tab row: Inbox, Apply, Tracker, then Sign out
  5. One panel
  6. Notes, closed `<details>`, below the panels
- Panels stay mounted. The inactive ones use the `hidden` attribute so a scan, a half-filled paste, and board inputs survive a tab change.
- Remember the open panel in `sessionStorage` key `desk-panel` (`inbox`, `apply`, or `tracker`). Missing or unknown value opens Inbox.
- Signed-in work column is `max-w-5xl`. Page wrapper stays `max-w-7xl`. Password form stays `max-w-3xl`.
- Body copy on Desk panels is `text-sm text-textLight`. Section intros are one short line, not `text-lg`.
- Job titles stay underlined links. Size drops from `text-xl` to `text-base font-semibold`.
- Row padding `py-4`. Hairline `border-b border-black/10`, not on the last row. No cards, shadows, icons, or new colors.

### Inbox panel

- Find jobs / Refresh scan stays the only filled pill.
- Intro, saved-shortlist date, empty state, skipped line, source errors, and Singapore / Bangladesh block stay.
- Overflow heading is `text-base font-semibold`, not `text-2xl`.
- Letter-doc hint once, under the intro. Not on every row.
- Each Apply row, in order:
  1. Title link, and on the same line the score (`Score 72`, mono, muted, wraps if needed)
  2. One muted line: company · location · source · application title
  3. One action line: Apply CV, ATS draft, Download letter, Applied, Skip
- Saved · Applied / Skip flash stays about 1 second, then the row leaves.
- No per-row application-title paragraph and no per-row score paragraph.

### Apply panel

- Top line: CV Doc and Cover letter Doc (existing hrefs).
- One muted line: existing apply-docs intro.
- Also apply heading, one intro line, the shared filter once, then the adds line once.
- Each board is one hairline row, not a stacked essay:
  1. Mark (mono box, `h-8 w-8`) and name
  2. Outbound links, then the board note in muted small type on the next line
  3. Sent, When, Add on one wrapping line
- Enter in the Sent field submits that board’s Add.
- After a successful add, that row shows `Saved · {name} · {count}` for about 1 second (same timing as the Inbox flash). Header `Applied: N` updates. The log list itself is on Tracker.
- Paste a job is open on this panel (not a closed disclosure). Evaluate stays the filled pill. Result layout stays; pack and status actions use the same text-action row as Inbox.

### Tracker panel

- Intro, job list, Rejected stage select, Clear, Interview Prep, and Logged by hand stay.
- Do not repeat `Applied: N` here.
- Each job row:
  1. Title link
  2. One muted line: company · status word · stage word when Rejected
  3. Status select, stage select when Rejected, Clear
- Prep stays inside `<details>` on Interview rows only.
- Logged by hand stays under the jobs, each log one line plus Clear.

### Header count

- `Applied: N` uses the existing total: jobs with status `applied`, plus manual log counts.
- Hide the line until the first `/desk/track` GET returns, then always show it, including 0.
- A mark, add, or clear anywhere updates it through the existing `desk-tracker-changed` event.

### Tabs and Sign out

- Three buttons. Active: `text-textDark font-semibold underline underline-offset-4`. Idle: `text-textLight`, no underline.
- `role="tablist"` / `role="tab"` / `role="tabpanel"`, `aria-selected`, panel labelled by its tab.
- No second H2 that repeats the tab name. Overflow, Also apply, Paste a job, and Logged by hand keep their own headings.
- Sign out is a text action on the tab row (right side, wraps on narrow screens). It is not an outline pill. Password **Open** stays the filled pill.

## Out of scope

- New boards, URL changes, fetch clients, fit rules, score weights, discovery sources
- `2.28` week/month stats
- Tracker statuses, stages, manual-count cap, gist store
- Auto-apply, new routes, public nav, footer, sitemap, theme, dark mode
- Icons, cards, dashboards, search boxes, drag and drop
- Hiding the public nav on `/desk`

## User-facing behavior

1. Sign in. Password form is unchanged.
2. Land on Inbox. Find jobs, open a title, mark Applied. The row flashes, leaves, and header Applied goes up by 1. Refresh returns to Inbox unless another panel was open in this tab session.
3. Open Apply. See the two Docs, the filter once, six board rows, and the paste form already open. Add `2` on LinkedIn for Today. The row flashes Saved. Header Applied goes up by 2. Switch to Inbox and back. The Sent field still shows what you left in it, except a successful add resets that field to 1 as it does today.
4. Open Tracker. See the job and `LinkedIn · 2 · Today`. Clear the log. Header Applied drops by 2.
5. Set a job to Rejected. Stage select appears. Set it back to Applied. Stage select goes away.
6. Open an Interview row’s Prep. Switch to Inbox and back. Prep’s open state may reset. The job row remains.
7. Notes stays closed under the panels on every tab. Open it, save a note, switch tabs. The note remains after reopen.
8. Narrow viewport: tabs, board controls, and action lines wrap. No sideways page scroll.
9. Public pages unchanged.

## UI notes

- Tokens stay paper, ink, `textLight`, `border-black/10`, `font-sans` for UI, `font-display` for the Desk H1 only, `font-mono` for the score and the board mark.
- Filled pills: Find jobs / Refresh scan, Evaluate, and the password Open button. Nothing else.
- Text actions: existing `deskTextActionClass`.
- Selects and the Sent input: existing paper field, `border-black/10`, `px-3 py-2`. Sent input stays about `w-24`.
- Tab row: `flex flex-wrap items-baseline gap-x-6 gap-y-2` with Sign out `sm:ml-auto`.
- Board row: `flex flex-wrap items-baseline gap-x-4 gap-y-2`. Note is `basis-full` so it sits under the name without becoming a card.
- Inbox title row: `flex flex-wrap items-baseline justify-between gap-x-4`.
- Do not add a font, a hex color, or a radius other than the pills that remain.
