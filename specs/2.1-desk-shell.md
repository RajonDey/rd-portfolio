# 2.1 Desk shell

## Status

`done`

## Goal

`/desk` exists as an empty private home in local `next dev`: password session, fail-closed 404 when locked, `noindex`, not in sitemap or nav. Production `/desk` is 404.

## Why

`2.0` locked the overlay and the `/desk` exception. This unit is the gated empty shell so `2.2` can add paste-JD without touching the public hiring document.

## In scope

- `src/app/desk/` empty home and session POST.
- `src/lib/desk/access.ts` and `src/lib/desk/copy.ts` (no scoring, no PDFs).
- One env password: `DESK_PASSWORD` in gitignored `.env.local`.
- Desk is on only when `NODE_ENV === "development"` and `DESK_PASSWORD` is set. Otherwise `notFound()` (404).
- Unauthenticated GET `/desk` in production: 404, same as a missing page, not a branded login URL on the public origin.
- In development with a password set: GET `/desk` without a session shows a minimal password form (local only, `noindex`). POST `/desk/session` sets an httpOnly cookie or 404s on a bad password.
- Layout metadata: `robots: { index: false, follow: false }`. Do not use `getPageShareMetadata` (no public canonical for `/desk`).
- `public/robots.txt`: `Disallow: /desk`.
- Sitemap unchanged (no `/desk` URL).
- Nav and footer unchanged (no Desk link).
- `export const dynamic = "force-dynamic"` on the desk layout so production does not bake a public page.
- Patch `context/architecture.md`, `context/job-search-profile.md` desk-boundary line, `AGENTS.md`, tracker, spec README.

## Out of scope

- Fit scoring, PDF packs, job search, email, tracker (`2.2`+)
- Clerk / OAuth / user tables / database
- `DESK_ENABLED` or hosting `/desk` on Vercel (later spec)
- Middleware rewrite unless the layout gate is not enough
- Auto-apply
- Public copy, OG, JSON-LD, or visual-system changes
- Footer on `/desk`

## User-facing behavior

**Public origin / `next start` / Vercel**

1. Visit `/desk` (or `/desk/session`). Response is 404. No password form.
2. Home, Work, Writing, About, footer: unchanged. No Desk link.
3. `https://portfolio.rajondey.com/sitemap.xml` does not list `/desk`.
4. `robots.txt` disallows `/desk`.

**Local `npm run dev` with `DESK_PASSWORD` in `.env.local`**

1. Open `/desk`. Enter the password. Submit Open.
2. Cookie is set. Empty desk home: kicker Private, H1 Desk, one sentence, Sign out.
3. Wrong password or missing password env: 404, not an error toast.
4. Sign out clears the cookie and returns to the password form (still local-only).
5. Public nav still has Work · Writing · About · CV only.
