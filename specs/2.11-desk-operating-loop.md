## User-facing behavior

1. Monday: read the reminder email. Open postings that look real. Open Desk.
2. On Desk: download a pack only if sending that file, or use the matching Google Doc. Apply by hand on the company site.
3. Mark Applied, Skip, Silence, or later Interview. Delete the download from Downloads. Do not save extra CVs to Drive.
4. Paste a job when the posting was not in the scan.
5. Public site unchanged.

Add `DESK_LOOP_INTRO` in `src/lib/desk/copy.ts`:

Overlay **Weekly loop** (paste into `context/job-search-profile.md`, no em dashes):

```
## Weekly loop

1. Monday mail is a reminder. Nothing was submitted. No CV or letter is attached.
2. Open the posting. If it is a real fit, open Desk (`https://portfolio.rajondey.com/desk`).
3. Inbox lists Apply hits. The title is the posting. Paste a job when the posting was not in the scan (including LinkedIn).
4. Apply by hand on the company site. Never auto-submit.
5. Download CV or letter from Desk only when you will send that file. Or use the matching Google Doc (SWE default or Frontend) from the CV variants table. Which file is the apply CV is `2.12`.
6. Mark the tracker: Applied (you sent it), Skip (you will not apply), Silence (hide without applying), Interview (they replied). Clear only if you hid it by mistake. All four statuses hide the URL from Find jobs and Monday mail.
7. Delete the downloaded PDFs from Downloads. Do not save extra copies to Drive. `.desk-out` pack PDFs are already removed on Applied (`2.10`). The tracker row is the record.
```

Also update the quality bar line to cite `2.5`/`2.9` for the weekly cap.
