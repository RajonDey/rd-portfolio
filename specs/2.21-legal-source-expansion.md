# 2.21 Legal source expansion

## Status

`done`

## Goal

Find jobs and Monday mail also scan Remotive’s public JSON API (geo-filtered) and the current Hacker News “Who is Hiring?” thread via the public Algolia API. Same `2.18` vetoes and `2.19` score. Relocate.me, LinkedIn, Wellfound, Otta, YC Work at a Startup, VanHack, Jaabz, Calyptus, SuperCoder, and Job Bank stay paste-only.

## Why

Arbeitnow + eight ATS boards miss visa-friendly remote/EU posts that legal public feeds already publish. Relocate.me is the best *idea* but has no official public API (third-party scrapers are out). Depends on `2.18`–`2.20` so new volume is filtered, scored, and queried on purpose.

## In scope

- Remotive: `GET https://remotive.com/api/remote-jobs` with `category=software-dev` and `search` from `2.20` queries (one request per query or one software-dev pull then filter — pick the smaller payload; timeout 8s, 3MB cap, existing User-Agent). Allowlist `remotive.com` / `www.remotive.com`.
  - Keep a job only if `candidate_required_location` or description matches overlay geo (Germany / Netherlands / Canada / Europe) **or** visa/relocation language, and `2.18` does not skip.
  - Drop US-only / worldwide-with-US-authorization via `2.18`.
  - `job_type` contract/freelance/internship → skip (also `2.18`).
  - Attribution: Inbox/weekly source label `Remotive`; posting URL is Remotive’s `url` (their ToS: link back, do not rehost as a third-party job board).
- HN Who is Hiring: public Algolia only. Allowlist `hn.algolia.com`.
  - Find the latest story whose title matches `Ask HN: Who is Hiring?`.
  - Fetch that item’s comments (same 8s / 3MB). Treat each top-level comment as a job blob (title/company guessed from first line; url = `https://news.ycombinator.com/item?id={commentId}`).
  - Run location prefilter + overlay title + `2.18` + `2.19`. Do not fetch random HN jobs.
- Dedupe with existing URL/title keys. Failed source = note, not a failed scan.
- Copy: Find jobs intro names Remotive and HN in addition to Arbeitnow + curated boards. Paste intro from `2.18` unchanged.
- Patch overlay discovery sources, architecture allowlist, progress tracker, spec README.

## Out of scope

- Relocate.me scrape or unofficial “Relocate API”
- LinkedIn, Indeed, StepStone, Wellfound, Otta, VanHack, Jaabz, Calyptus, SuperCoder, Job Bank
- YC Work at a Startup (login / reverse-engineered API)
- We Work Remotely RSS (defer; US-remote heavy)
- Techreviewer
- New ATS company tokens (`2.22`)
- Apify, browser scrape, extra npm XML parsers if Algolia JSON suffices
- Auto-apply, public site

## User-facing behavior

1. Sign in. Find jobs. Apply hits may include Remotive and HN rows with those source labels. Titles still open the posting.
2. Hits still pass `2.18` / `2.19`. Caps unchanged.
3. If Remotive or Algolia fails, that name appears under sources that failed; Arbeitnow/ATS still run.
4. Paste remains the path for Relocate, LinkedIn, Job Bank, SuperCoder. Public site unchanged.
